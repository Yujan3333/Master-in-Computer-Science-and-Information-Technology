

| Feature                   | **RDBMS (Relational)**         | **OODBMS (Object-Oriented)**                              | **ORDBMS (Object-Relational)**                    |
| ------------------------- | ------------------------------ | --------------------------------------------------------- | ------------------------------------------------- |
| **Data Model**            | Tables (rows & columns)        | Objects (attributes + methods)                            | Tables with object extensions (can store objects) |
| **Support for OOP**       | ❌ No                           | ✅ Full support (inheritance, polymorphism, encapsulation) | ✅ Partial support (user-defined types, methods)   |
| **Handling Complex Data** | Difficult                      | Easy (supports multimedia, nested objects)                | Moderate (extensions to handle complex data)      |
| **Query Language**        | SQL                            | OQL or language APIs                                      | Extended SQL (supports objects)                   |
| **Performance**           | Good for transactional systems | Good for applications with complex objects                | Combines RDBMS reliability + some object features |
| **Examples / Use Cases**  | Banking, Payroll               | CAD, GIS, Multimedia                                      | Advanced web apps, scientific databases           |

---

**Exam shortcut (one-liner):**

> **RDBMS = tables, simple data; OODBMS = objects, complex data; ORDBMS = tables + object features (hybrid).**
