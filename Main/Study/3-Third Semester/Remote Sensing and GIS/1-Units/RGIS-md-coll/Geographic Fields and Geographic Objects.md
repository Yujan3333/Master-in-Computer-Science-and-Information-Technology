# Geographic Fields

## Definition

A **geographic field** is a phenomenon that has **a value at every location** in the study area.

In other words,

> **Every point has some measurable value.**

---

## Examples

| Geographic Field | Value Measured |
| ---------------- | -------------- |
| Temperature      | °C             |
| Elevation        | meters         |
| Rainfall         | mm             |
| Air pressure     | hPa            |

Example:

```text
Study Area

20°C   22°C   24°C

21°C   23°C   25°C

19°C   21°C   23°C
```

Every location has a temperature value.

---

# Types of Geographic Fields

## 1. Continuous Field

Values **change gradually** from one place to another.

Examples:

* Temperature
* Elevation
* Rainfall
* Air pressure

Example:

```text
20°C → 21°C → 22°C → 23°C
```

There is a smooth change.

---

## 2. Discrete Field

The area is divided into **distinct categories**, where each location belongs to only one class.

Examples:

* Land use
* Soil type
* Administrative boundaries

Example:

```text
Forest | Agriculture | Urban
```

Each location belongs to one category.

---

# Geographic Objects

## Definition

A **geographic object** is a feature that exists **only at specific locations**, not everywhere.

Unlike fields, objects have **clear boundaries**.

---

## Examples

* Buildings
* Roads
* Rivers
* Schools
* Trees
* Bridges

Example:

```text
Study Area

      School

Road -----------

          House
```

Only certain places contain these objects.

---

# Easy Difference

| Geographic Field                | Geographic Object                       |
| ------------------------------- | --------------------------------------- |
| Exists everywhere               | Exists only in certain locations        |
| Every point has a value         | Only specific places contain the object |
| Usually continuous              | Usually has clear boundaries            |
| Example: Temperature, Elevation | Example: Building, Road, River          |

---

# Natural vs Man-made

Generally:

* 🌿 **Natural phenomena** → Mostly **Fields**

  * Temperature
  * Elevation
  * Rainfall

* 🏢 **Man-made phenomena** → Mostly **Objects**

  * Buildings
  * Roads
  * Bridges

---

## Memory Trick

### **Field = Fill**

A **field fills the entire area**, so every location has a value.

### **Object = One place**

An **object exists only at a particular location**.

**Example:**

* 🌡️ Temperature → **Field**
* 🏫 School → **Object**
