# Map Elements 

| **Map Element**       | **Short Description**                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Data Frame**        | The main area where the map and ***geographic features are displayed.***                                       |
| **Title**             | Describes the subject or purpose of the map.                                                                   |
| **Legend**            | Explains the meaning of symbols, colors, and patterns used on the map.                                         |
| **Scale**             | Shows the relationship between map distance and real-world distance (e.g., 1:50,000).                          |
| **North Arrow**       | Indicates the north direction to help orient the map.                                                          |
| **Projection System** | Specifies the map projection and coordinate system used to represent the Earth's curved surface on a flat map. |
| **Grid**              | Network of horizontal and vertical lines showing coordinates (latitude/longitude or UTM) for locating places.  |
| **Source/Citation**   | Indicates where the map data came from and gives credit to the data provider.                                  |
