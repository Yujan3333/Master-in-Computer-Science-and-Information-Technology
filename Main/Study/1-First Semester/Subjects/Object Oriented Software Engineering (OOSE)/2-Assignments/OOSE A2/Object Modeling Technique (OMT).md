- **OMT** is about _describing_ different facets of a system using multiple models
- It is developed by **James Rumbaugh**.
## Key Idea
System is modeled through 3 perspective ->
- **Object Model:** Describes the *static structure* of objects, their attributes, and relationships.
- **Dynamic Model:** Describes the *behavior* of objects over time, including states, transitions, and events.
- **Functional Model:** Describes the *data transformations* within the system using data flow diagrams.
## Process
Involves identifying objects and classes, their relationships, their behavior in response to events, and the flow of data through the system. It uses various diagrams to represent these models.
## Strengths
Provides a **holistic** (Looking something as a whole) view of the system by considering static structure, dynamic behavior, and functional aspects.

- It was a significant precursor to the Unified Modeling Language (UML).
## Limitations
The three models can sometimes be developed somewhat independently, potentially leading to *inconsistencies* if not managed carefully.
## Use Case
General-purpose system modeling (later merged into UML).
