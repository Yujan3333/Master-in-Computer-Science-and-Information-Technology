## 1. Q. Why should we study programming languages? (5 Marks)

**Ans:**

1. To improve algorithm development.
2. To use existing languages more effectively.
3. To increase programming vocabulary.
4. To choose the right language for a project.
5. To learn new languages easily.
6. To design new programming languages. 

---

## 2. Q. Define Syntax.

**Ans:**
Syntax is the set of rules that defines the correct structure or grammar of a programming language. 

---

## 3. Q. Define Semantics.

**Ans:**
Semantics is the meaning of syntactically correct statements in a programming language. 

---

## 4. Q. What is a Programming Paradigm?

**Ans:**
A programming paradigm is a style or approach to writing and organizing programs. 

---

## 5. Q. Differentiate Imperative and Declarative Programming.

**Ans:**

| Imperative                             | Declarative                             |
| -------------------------------------- | --------------------------------------- |
| Focuses on **how** to solve a problem. | Focuses on **what** result is required. |
| Uses sequence of commands.             | Uses logic and expressions.             |
| Control flow is important.             | Control flow is hidden.                 |
| Examples: C, C++, Java                 | Examples: LISP, Prolog                  |



---

## 6. Q. What is Orthogonality?

**Ans:**
Orthogonality is the ability to combine language features in all meaningful ways without restrictions. 

---

## 7. Q. What is Support for Abstraction?

**Ans:**
Support for abstraction allows programmers to define data types and operations as self-contained units while hiding implementation details. 

---

## 8. Q. What is Portability?

**Ans:**
Portability is the ability of a program to run on different computer systems with little or no modification. 

---

## 9. Q. What are the Attributes of a Good Programming Language? (5 Marks)

**Ans:**

* Clarity, simplicity and unity
* Orthogonality
* Naturalness
* Support for abstraction
* Ease of program verification
* Good programming environment
* Portability
* Low cost of use 

---

## 10. Q. What is Language Standardization?

**Ans:**
Language standardization is the process of defining standard rules for a programming language so that all implementations behave consistently. 

---

## 11. Q. What are the Types of Language Standards?

**Ans:**

1. Proprietary Standard
2. Consensus Standard 

---

## 12. Q. What is a Programming Environment?

**Ans:**
A programming environment is a collection of software tools used to create, test, debug, and execute programs. 

---

## 13. Q. What is Separate Compilation?

**Ans:**
Separate compilation allows different parts of a program to be compiled independently and later linked into a complete program. 

---

## 14. Q. What is a Breakpoint?

**Ans:**
A breakpoint is a specified point in a program where execution stops temporarily, allowing the programmer to inspect and debug the program. 

---

## 15. Q. What is an Assertion?

**Ans:**
An assertion is a condition inserted into a program to verify that certain conditions hold during execution. 

---

## 16. Q. What is JCL (Job Control Language)?

**Ans:**
JCL is a scripting language used in IBM mainframe systems to specify how programs should be executed and how input/output data should be processed. 

---

## 17. Q. What is Distributed Computing?

**Ans:**
Distributed computing is a model in which software components run on multiple computers but work together as a single system. 

---

## 18. Q. What is an Embedded System?

**Ans:**
An embedded system is a computer system designed to control a specific function within a larger system, such as a car or industrial machine.
