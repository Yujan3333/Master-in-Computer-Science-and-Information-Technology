# Interpretation Keys in Remote Sensing

## Definition

An **interpretation key** is a **guide or set of rules** used to identify objects in aerial photographs or satellite images.

It helps the interpreter recognize features correctly using visual clues.

---

## Interpretation Elements Used

When preparing an interpretation key, consider:

* Size
* Shape
* Shadow
* Tone
* Color
* Texture
* Pattern
* Site (Location)
* Association (Relationship with nearby objects)

Also consider:

* Time the image was taken
* Season
* Image scale
* Film/sensor type

---

# Types of Interpretation Keys

There are **two types**:

1. **Selective Key**
2. **Elimination Key**

---

# 1. Selective Key

## Definition

A **selective key** provides **examples of specific objects** and describes their characteristics.

It directly tells you:

> "If you see these characteristics, it is probably this object."

It is like a **reference guide** with examples.

### Example

| Object | Characteristics                  |
| ------ | -------------------------------- |
| River  | Long, winding, dark tone         |
| Road   | Long, narrow, smooth, light tone |
| Forest | Dark green, rough texture        |

If you see a **long winding dark object**, the key tells you:

➡️ It is likely a **river**.

### Easy Example

```text
Image Feature

Long + Curved + Dark

↓

Selective Key

River
```

---

## Advantages

* Easy to use.
* Quick identification.
* Good for beginners.

## Disadvantages

* Limited to listed examples.
* Difficult to identify unknown objects.

---

# 2. Elimination Key

## Definition

An **elimination key** identifies an object by **removing incorrect possibilities one by one**.

It follows a **step-by-step decision process** (decision tree).

Instead of saying:

> "This is a river."

It asks questions like:

* Is it long?
* Is it curved?
* Is the texture smooth?
* Is it connected to water?

Based on your answers, wrong options are eliminated until only one remains.

---

### Example

```text
Object

│

├── Is it long?

│        │

│        ├── No → Building

│        │

│        └── Yes

│

├── Is it curved?

│        │

│        ├── No → Road

│        │

│        └── Yes

│

└── River
```

Here:

* Not a building
* Not a road
* Therefore → River

---

## Advantages

* More accurate.
* Useful for similar-looking objects.
* Systematic identification.

## Disadvantages

* Takes more time.
* More complex.

---

# Difference Between Selective and Elimination Keys

| Feature    | Selective Key                  | Elimination Key                  |
| ---------- | ------------------------------ | -------------------------------- |
| Method     | Uses examples of known objects | Uses step-by-step elimination    |
| Process    | Direct identification          | Decision tree (Yes/No questions) |
| Speed      | Faster                         | Slower                           |
| Complexity | Simple                         | More detailed                    |
| Best For   | Common, well-known features    | Similar or confusing features    |

---

# Easy Memory Trick

### Selective = **Select**

You **select** the object because it matches a known example.

Example:

> Long + Curved + Dark → **River**

---

### Elimination = **Eliminate**

You **eliminate** the wrong choices until only one object remains.

Example:

> Long? ✔️ → Curved? ✔️ → Water? ✔️ → **River**

---

## Exam Definition (2 Marks)

* **Selective Key:** An interpretation key that identifies objects by comparing them with predefined examples and descriptions of known features.
* **Elimination Key:** An interpretation key that identifies objects through a step-by-step process of eliminating incorrect possibilities using visual characteristics such as shape, tone, texture, and pattern.
