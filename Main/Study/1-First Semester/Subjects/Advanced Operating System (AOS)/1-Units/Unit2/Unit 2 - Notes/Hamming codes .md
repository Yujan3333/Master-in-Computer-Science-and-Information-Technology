### 🧠 **1. Hamming Code**

- **What is it?**  
    Hamming code is an **error detection and correction technique** used in computer memory and storage.
    
- **How it works:**  
    It adds **extra bits** (called **parity bits**) to the data so that if **one bit gets flipped** (error), it can detect and **correct** it.
    
- ✅ **Key Feature**:  
    It can **detect and correct single-bit errors**.
    
- 📌 **Use Case**:  
    Rarely used in modern RAID, but used in **RAID 2** (theoretical level).
