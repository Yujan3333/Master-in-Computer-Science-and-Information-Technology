An **Operating System (OS)** is a **software** that acts as a **bridge** between the **user** and the **computer hardware**.
### Main Roles of OS
- **Interface** between user and hardware  
    → Makes it easier for users and programs to work with the hardware.
	
- **Resource Manager**  
    → Manages the CPU, memory, files, and devices.
    
- **Extended Machine**  
    → Gives a simplified view of the hardware (like a virtual machine) so programmers don’t need to manage low-level details.
