
| Feature                      | RDBMS               | OODBMS               |
| ---------------------------- | ------------------- | -------------------- |
| Data model                   | Relational (tables) | Object-oriented      |
| Data storage                 | Rows & columns      | Objects              |
| Query language               | SQL                 | OQL / language-based |
| Relationship handling        | Foreign keys        | Object references    |
| Inheritance                  | Not supported       | Supported            |
| Encapsulation                | No                  | Yes                  |
| Impedance mismatch           | Yes                 | No                   |
| Schema flexibility           | Rigid               | Flexible             |
| Performance for complex data | Lower               | Higher               |
| Popularity                   | Very high           | Limited              |
