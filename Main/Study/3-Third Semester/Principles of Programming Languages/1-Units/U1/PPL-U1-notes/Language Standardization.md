# Language Standardization

## Meaning

**Language standardization** means creating official rules and specifications for a programming language so that all compilers and implementations behave consistently.

It ensures that programs written in one system can work correctly on another system.

---

## Ways to Validate a Programming Language Code

A programming language code can be checked using three approaches:

### 1. Language Reference Manual

* Read the manual provided by the vendor of the compiler.

### 2. Run a Program

* Write and execute code on your computer to observe behavior.

### 3. Language Standard

* Read the official standard document of the language.

### Common Usage

* **Option 2** is most common.
* **Option 1** is also used.
* **Option 3** is less commonly used.

---

## Problem Without Standards

Option 1 and 2 depend on a specific compiler implementation.

Issues:

* Another vendor’s compiler may behave differently.
* Large programs may fail when moved to another computer.
* Results may not be the same.
* Vendors may add incompatible new features.

---

## Need for Standardization

To solve these issues, programming languages have official standards.

All implementations should follow the same rules.

---

## Types of Standards

## 1. Proprietary Standards

* Defined by the company that owns the language.
* Controlled by a single vendor.
* May lead to incompatibility if many vendors extend it differently.

## 2. Consensus Standards

* Created by agreement among experts and organizations.
* Used to ensure uniformity among multiple implementations.
* Most common modern approach.

---

## Standard Organizations

Examples of organizations involved in standards:

* ANSI
* CBEMA
* IEEE
* BSI
* ISO
* NIST

---

# Three Important Issues in Standardization

## 1. Timeliness

When should a language be standardized?

* Too early → Not enough practical experience.
* Too late → Many incompatible versions already exist.

Best time: when language is mature but not fragmented.

---

## 2. Conformance

### Conformant Program

A program that uses only features defined in the standard.

### Conforming Compiler

A compiler that correctly translates standard programs and produces correct output.

---

## 3. Obsolescence

A standard may become outdated over time because:

* Technology changes
* New architectures appear
* Better language features are needed

So standards must be revised periodically.

---

# Short Summary

Language standardization creates common rules for programming languages so programs remain portable, reliable, and consistent across different compilers and systems.
