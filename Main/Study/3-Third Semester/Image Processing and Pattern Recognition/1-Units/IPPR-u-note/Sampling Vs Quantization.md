#ippr #third-semester 

| **Sampling**                                                                   | **Quantization**                                                                     |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| Converts **continuous spatial coordinates** into **discrete pixel locations**. | Converts **continuous intensity (gray-level)** values into **discrete gray levels**. |
| Determines the **number of pixels** in the image.                              | Determines the **number of intensity levels** (brightness values).                   |
| Affects **spatial resolution** (image detail).                                 | Affects **gray-level resolution** (brightness accuracy).                             |
| Works on the **x and y coordinates** of the image.                             | Works on the **amplitude/intensity** of each sampled pixel.                          |
| More sampling → More pixels → Sharper image.                                   | More quantization levels → Smoother brightness transitions.                          |
| Measured by image size (e.g., **512 × 512**, **1024 × 1024**).                 | Measured by gray levels (e.g., **2, 16, 64, 256** levels).                           |
