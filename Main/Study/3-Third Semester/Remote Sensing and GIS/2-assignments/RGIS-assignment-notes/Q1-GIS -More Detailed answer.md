# ✅ **1. Concept and Core Functions of GIS (Unit 11)**

A **Geographic Information System (GIS)** is a system designed for **capturing, storing, manipulating, analyzing, and presenting spatial and attribute data**.

GIS is an **integration of spatial (location-based) and attribute (descriptive) information**.

---

## 🔹 **Key Components of GIS**

* Hardware
* Software
* Data
* People
* Methods

---

## 🔹 **Core Functions of GIS**

### 1. Data Input

* Collection of spatial data from:

  * Remote sensing
  * GPS (GNSS)
  * Maps and surveys
* Conversion into digital format

---

### 2. Data Storage and Management

* Data stored in databases
* Organized in **layers (thematic layers)**:

  * Roads
  * Land use
  * Rivers

---

### 3. Data Manipulation

* Editing and updating data
* Coordinate transformation
* Data correction

---

### 4. Spatial Analysis

* Core strength of GIS
* Includes:

  * Overlay analysis
  * Buffering
  * Network analysis
  * Query operations

---

### 5. Data Output and Presentation

* Results presented as:

  * Maps
  * Tables
  * Reports

---

## ✏️ Diagram (Draw in exam)

```
Data Input → Data Storage → Analysis → Output
```

# 🌍 **2. GPS / GNSS for Spatial Data Acquisition (Unit 6)**

## 🔹 **Definition**

**Global Navigation Satellite System (GNSS)** (including GPS) is used to determine **accurate position on Earth**.

---

## 🔹 **Working Principle**

* Satellites transmit signals
* Receiver collects signals from multiple satellites
* Position calculated using **distance measurement (triangulation method)**

---

## 🔹 **Output Data**

* Latitude
* Longitude
* Elevation

---

## 🔹 **Use in GIS**

* Collection of **ground truth data**
* Accurate location of features (points, roads, boundaries)

---

# 🛰️ **3. Remote Sensing for Spatial Data Acquisition (Unit 1 & Unit 10)**

## 🔹 **Definition**

Remote sensing is the science of acquiring information about Earth **without direct contact**, using sensors.

---

## 🔹 **Remote Sensing Process (as per syllabus)**

1. Source of energy (Sun or sensor)
2. Interaction with atmosphere
3. Interaction with target
4. Recording by sensor
5. Transmission and processing
6. Interpretation and analysis

---

## 🔹 **Output**

* Satellite images
* Land use/land cover data
* Environmental information

---

# 🔗 **4. Integration of GPS & Remote Sensing Data into GIS (Unit 10)**

GIS integrates data from multiple sources for analysis.

---

## 🔹 **Integration Process (Syllabus-Based)**

### 1. Data Acquisition

* Remote sensing → Raster data
* GNSS → Point data
* Ground truth → Field data

---

### 2. Data Pre-processing

* Correction of errors
* Image enhancement
* Georeferencing

---

### 3. Data Integration

* Combining:

  * Remote sensing data
  * Ground truth data
  * Ancillary data

---

### 4. Data Transformation

* Conversion between raster and vector
* Standardization of coordinate systems

---

### 5. GIS Database Creation

* Data stored in structured format
* Organized into layers

---

### 6. Data Analysis

* Overlay analysis
* Classification
* Spatial modeling

---

### 7. Presentation

* Final output:

  * Maps
  * Charts
  * Reports

---
