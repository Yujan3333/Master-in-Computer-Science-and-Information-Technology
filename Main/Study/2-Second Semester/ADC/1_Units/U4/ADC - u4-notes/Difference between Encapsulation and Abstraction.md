| Encapsulation                                                            | Abstraction                                                           |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| It is about **hiding data** and protecting it from outside access        | It is about **hiding complexity** and showing only essential features |
| Focuses on **how data is protected**                                     | Focuses on **what the object does**                                   |
| Achieved using **access modifiers** (private, protected, public)         | Achieved using **abstract classes and interfaces**                    |
| Binds data and methods together into a single unit (class)               | Separates *what to do* from *how to do it*                            |
| Example: making variables private and accessing them via getters/setters | Example: using a `Vehicle` interface with `start()` method            |
