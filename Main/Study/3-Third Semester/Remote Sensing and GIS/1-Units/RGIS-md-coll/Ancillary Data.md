## Ancillary Data (Remote Sensing & GIS)

### Definition

**Ancillary data** is **additional supporting information** used together with remote sensing or GIS data to improve analysis, interpretation, and accuracy.

In simple words:

> **Ancillary data = Extra information that supports the main data.**

It is **not the primary data** (such as a satellite image), but it helps you understand or verify the results.

---

## Simple Example

Imagine you have a **satellite image** showing a green area.

From the image alone, you cannot be sure whether it is:

* Forest 🌲
* Crop field 🌾
* Grassland 🌿

Now you use:

* Soil map
* Rainfall data
* Elevation map
* Field survey

These extra datasets help identify the area correctly.

These are called **ancillary data**.

---

## Examples of Ancillary Data

* Soil maps
* Topographic maps
* Weather data
* Population data
* Geological maps
* Land records
* Road maps
* Administrative boundaries
* GPS measurements
* Existing land-use maps

---

## Why is Ancillary Data Important?

It helps to:

* Improve image classification accuracy.
* Reduce interpretation errors.
* Verify remote sensing results.
* Provide additional information about the study area.
* Support better decision-making.

---

## Real-Life Example

Suppose a satellite image shows a blue area.

Without ancillary data, you might think it is a **lake**.

Using:

* **Topographic map** → Confirms it is in a valley.
* **Weather data** → Shows heavy rainfall occurred recently.
* **Field survey (ground truth)** → Confirms it is a temporary flood.

Thus, ancillary data helps interpret the image correctly.

---

## Difference Between Ground Truth and Ancillary Data

| Ground Truth Data                           | Ancillary Data                                     |
| ------------------------------------------- | -------------------------------------------------- |
| Collected directly from the field           | Existing supporting information from other sources |
| Used to verify remote sensing results       | Used to support and improve analysis               |
| Example: Visiting a field to identify crops | Example: Soil maps, weather data, geological maps  |

---

## Memory Trick

* **Ground Truth** = **Go to the Ground** and check.
* **Ancillary Data** = **Additional (supporting) Data**.

Think of it like this:

```text
Satellite Image
       +
Ancillary Data (extra information)
       +
Ground Truth (field verification)
       ↓
More accurate results
```
