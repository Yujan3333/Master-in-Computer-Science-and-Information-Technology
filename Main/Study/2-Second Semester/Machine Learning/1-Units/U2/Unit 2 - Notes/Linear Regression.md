### ⭐ **Regression Analysis (Clean Explanation)**

**Regression analysis** is a process of **curve fitting**, where we model the relationship between **independent variables** (inputs) and **dependent variables** (output).
The relationship can be represented using an **m-th degree polynomial**.

---

### ⭐ **Polynomial Regression**

In polynomial regression, the model tries to fit a polynomial curve of degree **m** to the data.

These models are usually trained using the:

* **Least Mean Square (LMS) rule**, or
* **Widrow–Hoff rule**

Both methods minimize the prediction error by adjusting the model weights.

---

### ⭐ **Linear Regression (Special Case)**

If we assume that:

* the relationship between variables is **linear**, and
* there is only **one independent variable**,

then the regression equation becomes:

[ y = f(x) = w_0 + w_1 x ]

Where:

* ( w_0 ) = intercept (bias)
* ( w_1 ) = slope (weight) of the line
* ( x ) = input
* ( y ) = predicted output
