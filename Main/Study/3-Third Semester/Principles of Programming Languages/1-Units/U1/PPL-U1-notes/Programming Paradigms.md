## Programming Paradigms (Summary)

A **programming paradigm** is a style or method of programming. It provides principles and concepts for organizing code and solving problems.

There are **two main types**:

### 1. Imperative Paradigm

* Command-driven approach.
* Program executes as a sequence of statements step by step.
* Focuses on **how to do the task**.
* Uses control flow statements (if, loop, etc.).

**Example:** Giving a friend step-by-step directions to your house.

**Types of Imperative Programming:**

1. **Procedural Programming**

   * Uses functions/procedures.
   * Example: C programming language

2. **Object-Oriented Programming (OOP)**

   * Uses objects and classes.
   * Concepts: encapsulation, inheritance, polymorphism, abstraction.
   * Examples: C++, Java, Python

3. **Database Query Language**

   * Used to manage database data.
   * Example: SQL

---

### 2. Declarative Paradigm

* Focuses on logic and desired result.
* Emphasizes **what to do**, not how.
* Control flow is less important.

**Example:** Giving only your address and letting your friend choose the route.

**Types of Declarative Programming:**

1. **Functional Programming**

   * Uses mathematical functions.
   * Based on Lambda Calculus.
   * Example: LISP

2. **Logic Programming**

   * Based on facts, rules, and logical reasoning.
