Think of them like this:

**AI ⟶ ML ⟶ DL ⟶ NN**

Each one is a subset of the previous.

---

### 1. Artificial Intelligence (AI)

AI is the **big umbrella**.
It means making machines behave like humans: thinking, reasoning, problem-solving, decision-making.

Examples:

* Chess programs
* Expert systems
* Chatbots
* Game bots

AI can be:

* Rule-based (no learning)
* Learning-based (uses ML)

---

### 2. Machine Learning (ML)

ML is a part of AI.
It means machines **learn from data** instead of being explicitly programmed.

Model improves by experience:
$$
\text{Performance} \uparrow \text{ with more data}
$$

Examples:

* Spam detection
* Recommendation systems
* Image classification

Types:

* Supervised learning
* Unsupervised learning
* Reinforcement learning

---

### 3. Neural Networks (NN)

NN is a technique inside ML.
Inspired by the human brain.

Basic structure:

* Input layer
* Hidden layer(s)
* Output layer

Simple form:
$$
y = f(w_1x_1 + w_2x_2 + \dots + w_nx_n + b)
$$

Examples:

* Handwritten digit recognition
* Speech recognition

---

### 4. Deep Learning (DL)

DL is a type of NN with **many hidden layers** (“deep”).

So:

* NN → few layers
* DL → many layers

DL is powerful for:

* Images
* Videos
* Speech
* Natural language

Examples:

* Face recognition
* Self-driving cars
* Voice assistants

---

### Simple Table

| Term | Meaning                       | Learns from data? | Uses Neural Networks? |
| ---- | ----------------------------- | ----------------- | --------------------- |
| AI   | Broad concept of intelligence | Maybe             | Maybe                 |
| ML   | AI that learns from data      | Yes               | Sometimes             |
| NN   | ML model based on neurons     | Yes               | Yes                   |
| DL   | NN with many layers           | Yes               | Yes (deep)            |

---

### One-line memory trick:

* **AI** = Think like humans
* **ML** = Learn from data
* **NN** = Brain-inspired learning model
* **DL** = Big, deep neural networks
