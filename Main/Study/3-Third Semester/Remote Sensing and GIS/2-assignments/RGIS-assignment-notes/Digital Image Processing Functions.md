# ✅ **Classification in Image Analysis**

---

## 🔹 **1. Supervised Classification**

### 🔸 Principle

* In supervised classification, the user provides **training samples of known classes**.
* The system uses these samples to classify the entire image.

---

### 🔸 Workflow (Illustration ✏️)

```
Training Samples → Signature Extraction → Classification Algorithm → Classified Image
```

---

### 🔸 Advantages

* Produces **high accuracy** when training data is good.
* Provides **better control** over classification results.

---

### 🔸 Limitations

* Requires **expert knowledge** to select training data.
* Time-consuming process.

---

## 🔹 **2. Unsupervised Classification**

### 🔸 Principle

* In unsupervised classification, the system automatically **groups pixels based on similarity**.
* The user assigns class labels after clustering.

---

### 🔸 Workflow (Illustration ✏️)

```
Input Image → Clustering Algorithm → Pixel Groups → Class Labeling
```

---

### 🔸 Advantages

* Does not require training data.
* Simple and fast to perform.

---

### 🔸 Limitations

* Less accurate than supervised classification.
* Resulting classes may not match real-world categories properly.

---

# ✅ **Difference Between Supervised and Unsupervised Classification**

| Aspect          | Supervised Classification                                                                    | Unsupervised Classification                                                                   |
| --------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Principle**   | Uses **training data (known classes)** provided by the user to classify pixels.              | Groups pixels automatically based on **similarity without prior knowledge**.                  |
| **Workflow**    | Select training samples → Extract signatures → Apply classifier → Generate classified image. | Apply clustering algorithm → Group pixels → Assign labels to clusters.                        |
| **Advantages**  | Produces **high accuracy** when training data is correct and reliable.                       | Does not require training data and is **simple and fast** to apply.                           |
| **Limitations** | Requires **expert knowledge** and is time-consuming to prepare training data.                | Produces **less accurate results**, and classes may not match real-world categories properly. |


---

# ✅ **Conclusion**

Digital image processing functions play an important role in improving image quality and extracting useful information. Among these, classification is essential for identifying land cover types. Supervised classification provides higher accuracy with user guidance, while unsupervised classification is simpler but less precise.
