A **Network Operating System (NOS)** is an operating system that **manages network resources** and allows **multiple computers to communicate, share files, printers, and other devices** over a network.

- Concepts of FTP and Remote Desktop(*Telnet, ssh*)

- Computers are independent but connected via a network.
- Each system has its own OS, and users are aware of multiple machines.
- Example: Windows Server, Novell NetWare.

### 💡 Key Idea:
A **Network Operating System** gives users the ability to:

- Access shared **files and applications**,
    
- **Send messages** or communicate,
    
- Use **shared devices** (like printers),
    
- Log into the network from any computer (in some NOS setups).
