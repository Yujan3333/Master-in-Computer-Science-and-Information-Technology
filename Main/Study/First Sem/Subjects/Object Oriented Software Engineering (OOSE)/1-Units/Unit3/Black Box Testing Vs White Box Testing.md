


| **Aspect**        | **Black Box Testing**                 | **White Box Testing**                       |
| ----------------- | ------------------------------------- | ------------------------------------------- |
| 1. Code Knowledge | Not required                          | Required                                    |
| 2. Focus          | Tests **functionality** of the system | Tests **internal logic** and code structure |
| 3. Performed By   | Testers or end users                  | Developers or technical testers             |
| 4. Based On       | Requirements and specifications       | Source code and design                      |
| 5. Example        | Testing login input-output            | Checking loops, conditions, and branches    |
