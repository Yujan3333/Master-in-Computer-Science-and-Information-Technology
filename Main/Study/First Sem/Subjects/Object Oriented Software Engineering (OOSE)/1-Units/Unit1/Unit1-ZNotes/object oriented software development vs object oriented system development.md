| **Aspect**            | **OOSD (Object-Oriented Software Development)**   | **OOSyD (Object-Oriented System Development)**              |
| --------------------- | ------------------------------------------------- | ----------------------------------------------------------- |
| **Focus**             | Building the software application                 | Developing the entire system (software + hardware + more)   |
| **Scope**             | Narrow (only software-related)                    | Broad (includes software, hardware, networking, etc.)       |
| **Activities**        | Analysis, design, coding, and testing of software | System design, integration, deployment, maintenance         |
| **Level**             | Programming and software design level             | System architecture level                                   |
| **Hardware Involved** | ❌ No                                              | ✅ Yes                                                       |
| **Example**           | Making a student result app in Java               | Building a full smart classroom system (devices + software) |
| **Main Output**       | A working software program                        | A complete, functioning system                              |
