🔍 Understanding Bitonic Sort

Bitonic sort works on sequences that are bitonic - sequences that first increase then decrease (or vice versa). Since our sequences aren't bitonic, we first need to create a bitonic sequence by reversing one of them.

📋 Summary of Bitonic Sort Process

1. Preparation: Combined sequences A and B, reversing B to create a bitonic sequence

2. Stage 1: Performed distance-4 comparisons to split the bitonic sequence

3. Stage 2: Performed distance-2 comparisons to further organize the data

4. Stage 3: Performed distance-1 comparisons to complete the sort

Result: All 8 elements are now in ascending order: 1, 2, 3, 4, 5, 6, 7, 8
