### What is a Distributed System?

A **distributed system** is a collection of **loosely coupled processors** (also called **nodes**, **computers**, **machines**, or **hosts**) that are **interconnected by a communication network**. These systems work together to achieve a common goal but appear to users as a **single coherent system**.

### Key Features:
- **Loosely Coupled**: The processors operate independently and do not share memory.
    
- **Communication Network**: They communicate over a network using messages.
    
- **Transparency**: Ideally, the user does not need to know where a process or data is located.
    
- **Scalability**: Can be scaled by adding more nodes.
    
- **Fault Tolerance**: Can continue functioning even if some nodes fail.

### Reasons for Distributed Systems
- Resource Sharing - printer, specialized hardware
- Computation Speedup - load sharing or job migration
- Reliability - recover from site failure
- Communication - message passing
- Flexibility - Downsizing one large system to smaller systems
