
## 🧠 Prerequisites for Building an Intelligent Application (Summary)

### 1️⃣ Review of Functionality

* First, understand **what users do** with your application.
* Identify **where intelligence will add value** (better decisions, recommendations, automation).
* Focus on parts that can benefit from **smart features**.

👉 *Example:*
Search, recommendations, personalization, prediction.

---

### 2️⃣ Data

* Intelligence depends on **data**.
* Data can be:

  * **Internal** (user activity, logs, transactions)
  * **External** (data from the web or other services)
* Often, **internal data is enough**, but sometimes extra data is needed.

---

## 🌐 Ways to Get External Data from the Web

### 🔹 Crawling & Screen Scraping

* **Crawling:** Automatically visits websites and downloads public content.
* **Screen scraping:** Extracts useful information from HTML pages.
* Intelligent techniques can classify or analyze scraped data.

👉 *Example:* Extracting restaurant reviews and ratings from websites.

---

### 🔹 Website Syndication

* Content is **shared directly** from one website to another.
* Avoids repeated crawling.
* Common formats:

  * RSS 1.0
  * RSS 2.0
  * Atom

👉 *Used for:* news feeds, blog updates.

---

### 🔹 Web Services

* Allow different applications to **exchange data over the internet**.
* Use standard protocols like **HTTP**.
* Data is commonly exchanged using **XML**.
* Programs written in different languages can communicate.

---

### 🔹 RESTful Web Services

* Based on **REST architecture**.
* Everything is treated as a **resource**.
* Accessed using standard HTTP methods:

  * GET, POST, PUT, DELETE

---

## 📝 One-Paragraph Exam Answer

> To build an intelligent application, two prerequisites are required: understanding application functionality to identify where intelligence adds value, and availability of data. Data may be internal or obtained externally from the web. External data can be collected using crawling and screen scraping, website syndication (RSS/Atom), or web services. RESTful web services provide a standard way for applications to exchange data using HTTP protocols.
