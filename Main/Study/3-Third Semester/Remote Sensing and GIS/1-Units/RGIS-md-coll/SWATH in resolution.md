#rgis #third-semester 

| Feature                                | **Narrow Swath**                                                          | **Wide Swath**                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Coverage Area**                      | Covers a **small area** in one pass                                       | Covers a **large area** in one pass                                            |
| **Revisit Time (Temporal Resolution)** | Takes **15–20 days** (or more if cloudy) to cover the same area again     | Can cover the same area **daily or very frequently**                           |
| **Spatial Resolution**                 | **High** (more detail, clearer image)                                     | **Low** (less detail, blurrier image)                                          |
| **Data Volume**                        | Produces **more data**, requiring more storage and transmission           | Produces **less data**, requiring less storage and transmission                |
| **Viewing Angle**                      | Narrow viewing angle                                                      | Wide viewing angle                                                             |
| **Atmospheric Effects**                | Less affected by atmospheric scattering; image quality is more consistent | More affected by atmospheric scattering; image quality varies across the swath |
| **Best For**                           | Detailed mapping, urban planning, engineering                             | Weather monitoring, disaster monitoring, large-area mapping                    |
