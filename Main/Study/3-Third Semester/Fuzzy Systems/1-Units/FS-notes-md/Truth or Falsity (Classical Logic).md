## Imagine a Light Switch 💡

The light can only be:

* **ON** ✅
* **OFF** ✅

Can it be **50% ON**?

**No.**

This is **classical logic**.

---

## Example 1: Door

Question:

> Is the door open?

Possible answers:

* Open (True) ✅
* Closed (False) ✅

Can you answer

> "The door is 60% open."

Not in **classical logic**.

Classical logic only understands:

```text
True
or
False
```

---

# Principle of Excluded Middle

This law says:

> **Every statement is either TRUE or FALSE. There is no third option.**

### Example

Statement:

> "The fan is ON."

Possible answers:

```text
Fan ON?  → Yes (True)
```

or

```text
Fan ON?  → No (False)
```

Nothing else.

That's what **excluded middle** means.

The "middle" (like 50% true) is **excluded (not allowed).**

---

# Principle of Non-Contradiction

This law says:

> A statement **cannot be both TRUE and FALSE at the same time.**

### Example

Statement:

> "The fan is ON."

Can it be

```text
True
AND
False
```

at the same time?

❌ Impossible.

It must be **one or the other.**

---

# Why Fuzzy Logic Was Invented

Now think about this question:

> Is a 25-year-old person young?

Some people say

> Yes.

Others say

> Not really.

Classical logic forces you to choose:

```text
Young = True
```

or

```text
Young = False
```

But humans don't think like that.

We think

> "He is **somewhat young**."

Fuzzy logic allows this.

Example:

```text
Young = 0.7
Old = 0.2
```

Both can have some truth.

---

# Another Example

Temperature = **29°C**

Classical Logic asks

> Is it HOT?

Answer must be

```text
Hot = True
```

or

```text
Hot = False
```

Fuzzy Logic says

```text
Hot = 0.6
Warm = 0.8
Cold = 0
```

which matches human thinking much better.

---

## The easiest way to remember

### Classical Logic

```text
Only two answers

YES
NO
```

---

### Fuzzy Logic

```text
YES = 0.8

NO = 0.2
```

It allows **partial truth**.
