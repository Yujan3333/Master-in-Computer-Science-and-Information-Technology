# 1. Introduction

A **Geographic Information System (GIS)** is a computer system used to collect, manage, analyze, and display information related to locations on the Earth's surface.

Unlike ordinary databases, GIS stores both:

* **Spatial data (location)**
* **Attribute data (description)**

---

## Why GIS is Important?

GIS helps answer questions such as:

* Where is the nearest hospital?
* Which areas are flood-prone?
* Which roads need maintenance?
* Which land is suitable for farming?

---

## Applications

* Urban planning
* Agriculture
* Disaster management
* Transportation
* Environmental monitoring
* Forestry
* Public health
* Utility management

---

# 2. Definition

## Definition

> **GIS is a computer-based system designed to capture, store, manage, analyze, manipulate, and display geographically referenced (spatial) data.**

---

# 3. Key Components of GIS

A GIS consists of **five main components**.

```text
People
   │
Hardware ─ Software
   │
Data
   │
Methods
```

---

## A. Hardware

Physical equipment used to run GIS.

Examples:

* Computer
* GPS/GNSS receiver
* Scanner
* Plotter
* Printer
* Server

---

## B. Software

Programs used for GIS analysis.

Examples:

* ArcGIS
* QGIS
* GRASS GIS
* MapInfo

---

## C. Data

The most important component.

Types:

### Spatial Data

Shows location.

Examples:

* Roads
* Rivers
* Buildings
* Land parcels

---

### Attribute Data

Describes spatial objects.

Example:

| Road    | Width | Surface |
| ------- | ----- | ------- |
| Highway | 20 m  | Asphalt |

---

## D. People

Users of GIS.

Examples:

* Surveyors
* Engineers
* Researchers
* Government agencies
* Students

---

## E. Methods

Procedures and rules used for GIS analysis.

Examples:

* Data collection
* Data analysis
* Mapping standards

# 4. GIS – Integration of Spatial and Attribute Information

One of the most important concepts in GIS.

GIS combines:

## Spatial Information

"Where is it?"

Examples:

* Coordinates
* Shape
* Location

---

## Attribute Information

"What is it?"

Examples:

* Population
* Name
* Height
* Area
* Land use

---

## Example

A school on a GIS map:

### Spatial Data

* Latitude
* Longitude

### Attribute Data

* School name
* Number of students
* Principal
* Year established

---

# Spatial vs Attribute Data

| Spatial Data   | Attribute Data       |
| -------------- | -------------------- |
| Shows location | Describes the object |
| Coordinates    | Name                 |
| Shape          | Population           |
| Position       | Area                 |

# 6. GIS and Related Terms

## Spatial Data

Location-based information.

---

## Attribute Data

Descriptive information.

---

## Raster Data

Data stored as pixels.

Examples:

* Satellite images
* DEM

---

## Vector Data

Data represented by:

* Points
* Lines
* Polygons

Examples:

Point → School

Line → Road

Polygon → Lake

---

## Layer

A collection of similar geographic features.

Examples:

* Road layer
* River layer
* Building layer

---

# Raster vs Vector

| Raster           | Vector                  |
| ---------------- | ----------------------- |
| Pixels           | Points, lines, polygons |
| Continuous data  | Discrete objects        |
| Satellite images | Roads, buildings        |

# Advantages of GIS

* Efficient data management
* Accurate mapping
* Powerful spatial analysis
* Supports decision-making
* Easy integration with remote sensing and GNSS
* Saves time and cost

---

# Limitations of GIS

* High software and hardware costs
* Requires trained personnel
* Large data storage needs
* Data quality affects results
* Time-consuming database creation
