
### 1. Introduction to Cluster Analysis

Clustering is an **unsupervised learning** technique that groups data objects such that:

* Objects in the **same cluster** are similar
* Objects in **different clusters** are dissimilar

Goal:
$$\text{maximize intra-cluster similarity, minimize inter-cluster similarity}$$

---

## 2. Types of Data in Cluster Analysis

1. **Interval-scaled data**
   Numeric, continuous
   Example: height, weight

Distance:
$$d(i,j)=\sqrt{\sum (x_i-x_j)^2}$$

2. **Binary data**
   0/1 values

3. **Nominal data**
   Categories without order
   Example: color, gender

4. **Ordinal data**
   Ordered categories
   Example: ranks, grades

5. **Ratio-scaled data**
   Numeric with true zero

6. **Mixed-type data**
   Combination of all above

---

## 3. Categorization of Major Clustering Methods

1. Partitioning methods
2. Hierarchical methods
3. Density-based methods
4. Grid-based methods
5. Model-based methods

---

## 4. Partitioning Methods

Divide data into **k clusters**.

Example: **k-Means, k-Medoids**

k-Means objective:
$$\min \sum_{i=1}^{k}\sum_{x\in C_i}|x-\mu_i|^2$$

Where
$C_i$ = cluster
$\mu_i$ = centroid

Algorithm:

1. Choose k
2. Initialize centroids
3. Assign points to nearest centroid
4. Update centroid
5. Repeat until convergence

---

## 5. Density-Based Methods

Clusters are dense regions separated by sparse regions.

Example: **DBSCAN**

Parameters:

* $\varepsilon$ = neighborhood radius
* MinPts = minimum points

Point is core if:
$$|N_\varepsilon(p)| \ge MinPts$$

Advantages:

* Finds arbitrary shaped clusters
* Handles noise well

---

## 6. Grid-Based Methods

Data space is divided into **finite number of cells (grids)**.

Example:

* STING
* CLIQUE

Time complexity depends on **number of grids**, not number of objects.

---

## 7. Model-Based Clustering

Assumes data is generated by a **statistical model**.

Example: Gaussian Mixture Model (GMM)

Probability:
$$P(x)=\sum_{i=1}^{k}\pi_i \mathcal{N}(x|\mu_i,\Sigma_i)$$

Uses **EM algorithm**:

* E-step: compute probabilities
* M-step: update parameters

---

## 8. Outlier Analysis

Outliers = objects that **do not belong to any cluster**.

Distance-based:
$$d(p,neighbors) > threshold$$

Density-based:

* Points with very low density

Uses:

* Fraud detection
* Network intrusion
* Fault diagnosis
