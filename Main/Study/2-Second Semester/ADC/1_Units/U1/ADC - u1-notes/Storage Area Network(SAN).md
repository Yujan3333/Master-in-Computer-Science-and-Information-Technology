
## Storage Area Network (SAN)

The demand for higher storage capacity has increased rapidly.
Organizations are moving from fixed, static data centers to more **flexible and dynamic infrastructures**.
This has led to the adoption of **Storage Area Networks (SANs)**.

A **SAN** is a high-speed network that connects servers to shared storage devices.
Storage peripherals act as **nodes** on the network and can be attached or detached from servers easily.

This provides:

* Centralized storage
* Flexible configuration
* Better performance and scalability

---

## Key Features of SAN

* Storage devices are connected through a **high-speed network**.
* Servers can access storage dynamically.
* Storage can be placed **far from servers**.
* Supports multiple connectivity and performance options.

---

## Advantages of SANs

1. **Flexible connectivity**

   * Many-to-many connections between servers and storage devices.
   * Uses Fibre Channel hubs and switches.

2. **Long distance support**

   * Up to **10 km** separation between server and storage using fiber optic cables.

3. **High availability and isolation**

   * New servers or storage devices can be added without disturbing existing operations.

4. **Better resource utilization**

   * Storage can be shared among multiple servers efficiently.

---

## Problems / Challenges of SANs

* Combining storage systems from **multiple vendors** is complex.
* Must deal with **evolving standards** of:

  * Storage hardware
  * Storage management software
* High initial setup and management cost.

---

## One-line Exam Definition

> A Storage Area Network (SAN) is a high-speed network that connects servers to shared storage devices, providing flexible, scalable, and centralized storage management.
