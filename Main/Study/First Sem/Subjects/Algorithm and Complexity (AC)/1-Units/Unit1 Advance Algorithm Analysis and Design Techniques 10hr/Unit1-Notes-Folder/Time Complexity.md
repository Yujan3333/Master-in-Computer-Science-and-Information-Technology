- Time complexity describes how the *runtime* of an algorithm *grows* as the *input size increases.*
- It's an essential concept in computer science that helps you predict how efficient an algorithm will be for large inputs.
	
- **IT IS NOT COUNTING RUNTIME!** Its the *number of steps required to get the output* and Its *machine independent.*

### Three Types
- Big O - worst case
- Big Omega - best case
- Theta - average (Amortized)

| Symbol<br> | Meaning<br>   | Why Not Used Often               |
| ---------- | ------------- | -------------------------------- |
| **O**      | Worst case    | ✅ Default and safest             |
| **Ω**      | Best case     | ❌ Not useful for guarantees      |
| **Θ**      | Exact average | ❌ Hard to prove, varies by input |
