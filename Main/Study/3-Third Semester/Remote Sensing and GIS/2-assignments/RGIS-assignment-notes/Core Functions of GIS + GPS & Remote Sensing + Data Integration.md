## ✅ **1. Core Functions of Geographic Information System (GIS)**

A **Geographic Information System (GIS)** is a computer-based system used to **capture, store, manage, analyze, and display spatial (geographic) data**.

### 🔹 Core Functions:

### 1. Data Input (Capture)

* Collects spatial data from different sources:

  * Maps
  * Satellite images
  * GPS devices
* Converts data into digital form

---

### 2. Data Storage & Management

* Stores large amounts of geographic data in databases
* Organizes data into layers (roads, rivers, buildings)

---

### 3. Data Manipulation

* Editing and transforming data
* Examples:

  * Changing projection
  * Updating attributes
  * Cleaning errors

---

### 4. Spatial Analysis

* Performs analysis on geographic data
* Examples:

  * Overlay analysis
  * Buffering
  * Distance calculation

---

### 5. Data Output (Visualization)

* Displays results in:

  * Maps
  * Charts
  * Reports

---

# 🔗 **4. Integration of Data into GIS**

After collecting data from GPS and remote sensing, it is integrated into GIS.

---

### 🔹 Steps of Integration:

1. **Data Collection**

   * GPS → point data
   * Remote sensing → raster images

2. **Georeferencing**

   * Align data to real-world coordinates

3. **Data Conversion**

   * Raster ↔ Vector conversion if needed

4. **Layer Creation**

   * Different data stored as layers:

     * Roads
     * Buildings
     * Land use

5. **Database Storage**

   * Stored in GIS database

6. **Analysis & Visualization**

   * Overlay analysis
   * Map generation
