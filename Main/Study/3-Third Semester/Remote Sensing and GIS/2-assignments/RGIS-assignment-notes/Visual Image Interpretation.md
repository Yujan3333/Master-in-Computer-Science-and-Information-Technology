# ✅ **2. Scale in Image Interpretation**

### 🔹 Definition

Scale is the ratio between the distance on an image and the actual distance on the ground.

---

### 🔹 Importance

* Scale determines how much detail can be seen in an image.
* A larger scale image shows more detail, while a smaller scale image shows a larger area with less detail.

---

### 🔹 Effect of Scale

* Large-scale images help in identifying small features like buildings and roads clearly.
* Small-scale images are useful for observing large regions such as cities and landscapes.

---

### 🔹 Image Interpretation Keys

* Image interpretation keys are guidelines used to identify objects in images.
* Direct keys use visible features like tone and shape, while indirect keys use context and association.

# ✅ **5. Digital Image Processing Functions**

### 🔹 Common Functions

* Digital image processing includes enhancement, classification, filtering, and transformation.
* These functions help extract useful information from images.

---

### 🔹 Supervised Classification

* Supervised classification requires training data provided by the user.
* The system learns from known samples and classifies the rest of the image accordingly.
* It usually produces more accurate results when training data is good.

---

### 🔹 Unsupervised Classification

* Unsupervised classification does not require training data.
* The system automatically groups pixels based on similarity.
* The user later assigns meaning to the groups.

---

### 🔹 Difference (Simple Understanding)

* In supervised classification, the user guides the process.
* In unsupervised classification, the system finds patterns on its own.
