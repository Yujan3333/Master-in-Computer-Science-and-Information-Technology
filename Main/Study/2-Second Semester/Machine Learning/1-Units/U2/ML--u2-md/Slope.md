### **1️⃣ Mathematical definition (for a straight line)**

For a line:

$$
y = mx + c
$$

* **m** is the slope
* **c** is the y-intercept

The slope is:

$$
m = \frac{\text{change in } y}{\text{change in } x} = \frac{\Delta y}{\Delta x}
$$

So it tells you:

* How much **y goes up or down** when **x increases by 1**
* If slope > 0 → line goes **upwards**
* If slope < 0 → line goes **downwards**
* If slope = 0 → line is **flat**

---

### **2️⃣ Real-life examples**

1. Road:

   * A slope of 0 → flat road
   * A slope of 1 → go up 1 meter for every 1 meter forward

2. Economics:

   * Demand curve slope → how much quantity demanded changes for a price change

3. Physics:

   * Distance–time graph slope → **speed** (distance per time)

---

### **3️⃣ Intuition**

Think of slope as:

> “For every step you move right, how much do you go up or down?”
