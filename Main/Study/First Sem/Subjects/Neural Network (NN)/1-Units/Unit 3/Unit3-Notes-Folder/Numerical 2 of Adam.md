# Adaptive Control of Learning Rate - Complete Solution with Bias Correction

## Problem Setup
- **Network**: Simple ANN with logistic activation
- **Parameters**: α = 0.2, β = 0.8, β₁ = 0.8, β₂ = 0.8
- **Initial weights**: w₁ = 0.5, w₂ = 0.5
- **Training data**: 3 samples
- **Note**: Using bias correction for all applicable methods

| x₁  | x₂  | t   |
|-----|-----|-----|
| 1   | 0.6 | 0.8 |
| 0.5 | 0.5 | 0.6 |
| 0.2 | 0.8 | 0.3 |

## Step 1: Forward Pass and Gradient Calculation

### Sample 1: (1, 0.6, 0.8)
```
net = w₁x₁ + w₂x₂ = 0.5(1) + 0.5(0.6) = 0.8
y = σ(net) = 1/(1 + e^(-0.8)) = 0.689
error = t - y = 0.8 - 0.689 = 0.111
δ₁ = error × y × (1 - y) = 0.111 × 0.689 × 0.311 = 0.024
∇w₁ = δ₁ × x₁ = 0.024 × 1 = 0.024
∇w₂ = δ₁ × x₂ = 0.024 × 0.6 = 0.014
```

### Sample 2: (0.5, 0.5, 0.6)
```
net = w₁x₁ + w₂x₂ = 0.5(0.5) + 0.5(0.5) = 0.5
y = σ(net) = 1/(1 + e^(-0.5)) = 0.622
error = t - y = 0.6 - 0.622 = -0.022
δ₂ = error × y × (1 - y) = -0.022 × 0.622 × 0.378 = -0.005
∇w₁ = δ₂ × x₁ = -0.005 × 0.5 = -0.003
∇w₂ = δ₂ × x₂ = -0.005 × 0.5 = -0.003
```

### Sample 3: (0.2, 0.8, 0.3)
```
net = w₁x₁ + w₂x₂ = 0.5(0.2) + 0.5(0.8) = 0.5
y = σ(net) = 1/(1 + e^(-0.5)) = 0.622
error = t - y = 0.3 - 0.622 = -0.322
δ₃ = error × y × (1 - y) = -0.322 × 0.622 × 0.378 = -0.075
∇w₁ = δ₃ × x₁ = -0.075 × 0.2 = -0.015
∇w₂ = δ₃ × x₂ = -0.075 × 0.8 = -0.060
```

## Method 1: Momentum (Standard - No Bias Correction)

**Formula**: 
- $v_t = βv_{t-1} + α∇w_t$
- $w_{t+1} = w_t - v_t$

**Initial**: v₀ = 0, w₀ = [0.5, 0.5]

### Sample 1:
```
v₁ʷ¹ = 0.8(0) + 0.2(0.024) = 0.005
v₁ʷ² = 0.8(0) + 0.2(0.014) = 0.003
w₁ʷ¹ = 0.5 - 0.005 = 0.495
w₁ʷ² = 0.5 - 0.003 = 0.497
```

### Sample 2:
```
v₂ʷ¹ = 0.8(0.005) + 0.2(-0.003) = 0.003
v₂ʷ² = 0.8(0.003) + 0.2(-0.003) = 0.002
w₂ʷ¹ = 0.495 - 0.003 = 0.492
w₂ʷ² = 0.497 - 0.002 = 0.495
```

### Sample 3:
```
v₃ʷ¹ = 0.8(0.003) + 0.2(-0.015) = -0.001
v₃ʷ² = 0.8(0.002) + 0.2(-0.060) = -0.010
w₃ʷ¹ = 0.492 - (-0.001) = 0.493
w₃ʷ² = 0.495 - (-0.010) = 0.505
```

**Final Momentum weights**: w = [0.493, 0.505]

## Method 2: Adagrad (No Bias Correction)

**Formula**: 
- $G_t = G_{t-1} + (∇w_t)²$
- $w_{t+1} = w_t - (α/√(G_t + ε))∇w_t$

**Initial**: G₀ = 0, ε = 1e-8

### Sample 1:
```
G₁ʷ¹ = 0 + (0.024)² = 0.000576
G₁ʷ² = 0 + (0.014)² = 0.000196
w₁ʷ¹ = 0.5 - (0.2/√0.000576) × 0.024 = 0.5 - 0.2 = 0.300
w₁ʷ² = 0.5 - (0.2/√0.000196) × 0.014 = 0.5 - 0.2 = 0.300
```

### Sample 2:
```
G₂ʷ¹ = 0.000576 + (-0.003)² = 0.000585
G₂ʷ² = 0.000196 + (-0.003)² = 0.000205
w₂ʷ¹ = 0.300 - (0.2/√0.000585) × (-0.003) = 0.300 + 0.025 = 0.325
w₂ʷ² = 0.300 - (0.2/√0.000205) × (-0.003) = 0.300 + 0.042 = 0.342
```

### Sample 3:
```
G₃ʷ¹ = 0.000585 + (-0.015)² = 0.000810
G₃ʷ² = 0.000205 + (-0.060)² = 0.003805
w₃ʷ¹ = 0.325 - (0.2/√0.000810) × (-0.015) = 0.325 + 0.105 = 0.430
w₃ʷ² = 0.342 - (0.2/√0.003805) × (-0.060) = 0.342 + 0.195 = 0.537
```

**Final Adagrad weights**: w = [0.430, 0.537]

## Method 3: RMSProp with Bias Correction

**Formula**: 
- $v_t = βv_{t-1} + (1-β)(∇w_t)²$
- $v̂_t = v_t/(1-β^t)$  ← **Bias correction**
- $w_{t+1} = w_t - (α/√(v̂_t + ε))∇w_t$

**Initial**: v₀ = 0, β = 0.8, ε = 1e-8

### Sample 1 (t=1):
```
v₁ʷ¹ = 0.8(0) + 0.2(0.024)² = 0.000115
v₁ʷ² = 0.8(0) + 0.2(0.014)² = 0.000039
v̂₁ʷ¹ = 0.000115/(1-0.8¹) = 0.000575
v̂₁ʷ² = 0.000039/(1-0.8¹) = 0.000195
w₁ʷ¹ = 0.5 - (0.2/√0.000575) × 0.024 = 0.5 - 0.200 = 0.300
w₁ʷ² = 0.5 - (0.2/√0.000195) × 0.014 = 0.5 - 0.200 = 0.300
```

### Sample 2 (t=2):
```
v₂ʷ¹ = 0.8(0.000115) + 0.2(-0.003)² = 0.000094
v₂ʷ² = 0.8(0.000039) + 0.2(-0.003)² = 0.000033
v̂₂ʷ¹ = 0.000094/(1-0.8²) = 0.000261
v̂₂ʷ² = 0.000033/(1-0.8²) = 0.000092
w₂ʷ¹ = 0.300 - (0.2/√0.000261) × (-0.003) = 0.300 + 0.037 = 0.337
w₂ʷ² = 0.300 - (0.2/√0.000092) × (-0.003) = 0.300 + 0.063 = 0.363
```

### Sample 3 (t=3):
```
v₃ʷ¹ = 0.8(0.000094) + 0.2(-0.015)² = 0.000120
v₃ʷ² = 0.8(0.000033) + 0.2(-0.060)² = 0.000746
v̂₃ʷ¹ = 0.000120/(1-0.8³) = 0.000203
v̂₃ʷ² = 0.000746/(1-0.8³) = 0.001266
w₃ʷ¹ = 0.337 - (0.2/√0.000203) × (-0.015) = 0.337 + 0.211 = 0.548
w₃ʷ² = 0.363 - (0.2/√0.001266) × (-0.060) = 0.363 + 0.337 = 0.700
```

**Final RMSProp weights**: w = [0.548, 0.700]

## Method 4: Adam with Bias Correction

**Formula**: 
- $m_t = β₁m_{t-1} + (1-β₁)∇w_t$
- $v_t = β₂v_{t-1} + (1-β₂)(∇w_t)²$
- $m̂_t = m_t/(1-β₁^t)$  ← **Bias correction**
- $v̂_t = v_t/(1-β₂^t)$ ← **Bias correction**
- $w_{t+1} = w_t - α(m̂_t/√(v̂_t + ε))$

**Initial**: m₀ = 0, v₀ = 0, β₁ = 0.8, β₂ = 0.8, ε = 1e-8

### Sample 1 (t=1):
```
m₁ʷ¹ = 0.8(0) + 0.2(0.024) = 0.005
m₁ʷ² = 0.8(0) + 0.2(0.014) = 0.003
v₁ʷ¹ = 0.8(0) + 0.2(0.024)² = 0.000115
v₁ʷ² = 0.8(0) + 0.2(0.014)² = 0.000039

m̂₁ʷ¹ = 0.005/(1-0.8¹) = 0.025
m̂₁ʷ² = 0.003/(1-0.8¹) = 0.015
v̂₁ʷ¹ = 0.000115/(1-0.8¹) = 0.000575
v̂₁ʷ² = 0.000039/(1-0.8¹) = 0.000195

w₁ʷ¹ = 0.5 - 0.2 × (0.025/√0.000575) = 0.5 - 0.208 = 0.292
w₁ʷ² = 0.5 - 0.2 × (0.015/√0.000195) = 0.5 - 0.215 = 0.285
```

### Sample 2 (t=2):
```
m₂ʷ¹ = 0.8(0.005) + 0.2(-0.003) = 0.003
m₂ʷ² = 0.8(0.003) + 0.2(-0.003) = 0.002
v₂ʷ¹ = 0.8(0.000115) + 0.2(-0.003)² = 0.000094
v₂ʷ² = 0.8(0.000039) + 0.2(-0.003)² = 0.000033

m̂₂ʷ¹ = 0.003/(1-0.8²) = 0.008
m̂₂ʷ² = 0.002/(1-0.8²) = 0.006
v̂₂ʷ¹ = 0.000094/(1-0.8²) = 0.000261
v̂₂ʷ² = 0.000033/(1-0.8²) = 0.000092

w₂ʷ¹ = 0.292 - 0.2 × (0.008/√0.000261) = 0.292 - 0.099 = 0.193
w₂ʷ² = 0.285 - 0.2 × (0.006/√0.000092) = 0.285 - 0.125 = 0.160
```

### Sample 3 (t=3):
```
m₃ʷ¹ = 0.8(0.003) + 0.2(-0.015) = -0.001
m₃ʷ² = 0.8(0.002) + 0.2(-0.060) = -0.010
v₃ʷ¹ = 0.8(0.000094) + 0.2(-0.015)² = 0.000120
v₃ʷ² = 0.8(0.000033) + 0.2(-0.060)² = 0.000746

m̂₃ʷ¹ = -0.001/(1-0.8³) = -0.002
m̂₃ʷ² = -0.010/(1-0.8³) = -0.017
v̂₃ʷ¹ = 0.000120/(1-0.8³) = 0.000203
v̂₃ʷ² = 0.000746/(1-0.8³) = 0.001266

w₃ʷ¹ = 0.193 - 0.2 × (-0.002/√0.000203) = 0.193 + 0.028 = 0.221
w₃ʷ² = 0.160 - 0.2 × (-0.017/√0.001266) = 0.160 + 0.095 = 0.255
```

**Final Adam weights**: w = [0.221, 0.255]

## Summary of Final Weights

| Method            | w₁    | w₂    | Notes |
|-------------------|-------|-------|-------|
| Momentum          | 0.493 | 0.505 | No bias correction (standard) |
| Adagrad           | 0.430 | 0.537 | No bias correction (standard) |
| RMSProp (biased)  | 0.548 | 0.700 | **With bias correction** |
| Adam              | 0.221 | 0.255 | With bias correction (standard) |

## Key Observations:

1. **Momentum**: Provides smooth updates with exponential moving average of gradients
2. **Adagrad**: Accumulates squared gradients, leading to decreasing effective learning rates
3. **RMSProp with Bias Correction**: Prevents learning rate decay and corrects for initialization bias, leading to larger weight updates than standard RMSProp
4. **Adam**: Combines momentum and adaptive learning rates with bias correction for both first and second moments

## Impact of Bias Correction:
- **RMSProp**: Bias correction significantly changed the final weights from [0.791, 0.999] to [0.548, 0.700]
- **Adam**: Already includes bias correction by default
- **Early iterations**: Bias correction has the largest impact in early training steps when the moving averages are small
