#### 🟢 **Logical Address (Virtual Address):**
- The address generated by the **CPU**.
    
- Used by the **program**.
    
- Not the actual location in RAM.
    

> Think of it like a room number on a hotel booking — not the real physical room yet.

---
#### 🔵 **Physical Address:**

- The real address in **main memory (RAM)**.
    
- This is where the data actually resides.
    

> Like the actual hotel room assigned when you check in.

---

### 🛠️ **Relocation: Mapping Logical → Physical**

- The OS must **convert logical addresses** to **physical addresses** before accessing memory.
    
- This is done using **two registers**:

|Register|Role|
|---|---|
|**Base Register**|Holds the **starting address** of the program in physical memory|
|**Limit Register**|Defines the **maximum allowed address range** for the program|
> [!note]+ ✅ **Mapped Address = Logical Address + Base**

---
### 🔐 **Memory Protection**

- The OS uses **Base and Limit** to ensure:
    
    - A process **can’t access memory** outside its allowed area.
        
    - This prevents **accidental or malicious memory access**.
        

> If the address is outside the allowed range → **trap/error** occurs.
