| Feature                 | Supervised Classification                    | Unsupervised Classification                |
| ----------------------- | -------------------------------------------- | ------------------------------------------ |
| **Basic Idea**          | Uses known labels to classify                | Finds patterns automatically               |
| **Training Data**       | Required (labeled samples)                   | Not required                               |
| **User Involvement**    | High (select training areas)                 | Low (mainly after clustering)              |
| **Control Over Output** | High (predefined classes like water, forest) | Low (clusters formed first, labeled later) |
| **Accuracy**            | Generally high                               | Moderate / lower                           |
| **Complexity**          | More effort (training phase)                 | Simpler and faster                         |
| **Output**              | Meaningful classes directly                  | Clusters (need interpretation)             |
| **Examples**            | Support Vector Machine, Random Forest        | K-Means Clustering, ISODATA                |
