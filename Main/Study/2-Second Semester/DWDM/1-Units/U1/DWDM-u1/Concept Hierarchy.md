A **concept hierarchy** is a way of organizing attribute values from **lower, more detailed levels** to **higher, more general levels**.

In simple words:

> It shows how specific data values can be grouped into broader categories.

It helps the system understand data at different levels of abstraction.

---

Another example with **Location**:

```
Street → City → State → Country
```

```
New Road → Kathmandu → Bagmati → Nepal
```

---

Why concept hierarchy is used:

* To **summarize data**
* To **reduce data complexity**
* To support **data generalization**
* To help in **OLAP operations** (roll-up and drill-down)
* To improve **data mining efficiency**

---

Exam-ready definition:

> A concept hierarchy is a hierarchical structure that organizes attribute values from specific (low-level) concepts to more general (high-level) concepts, enabling data generalization and multi-level data analysis.
