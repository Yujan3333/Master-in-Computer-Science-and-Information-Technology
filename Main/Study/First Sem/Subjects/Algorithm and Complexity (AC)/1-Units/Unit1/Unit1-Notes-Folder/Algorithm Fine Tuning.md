Changing the algorithm from **expensive** to cheaper side.
```md
Exponential - O(2^n), O(n!), etc

Polynomial (O(n^c) where c > 1) including Quadratic (O(n²))

Linearithmic O(n log n)

...

Linear - O(n)
Logarithmic - O(log n)
Constant- O(1)
```
##### Here,
`n` is the *input size*
