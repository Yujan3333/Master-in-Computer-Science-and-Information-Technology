- Input series: {0.2, 0.4, 0.6, 0.8}

- Initial hidden state: h₀ = [0; 0]

## Time Step 1: Input x₁ = 0.2

### Calculate h₁:

h₁ = σ(W_hh × h₀ + W_xh × x₁)

**Step by step:**

- W_hh × h₀ = [0.1 0.5; 0.5 0.9] × [0; 0] = [0; 0]
- W_xh × x₁ = [0.6; 0.2] × 0.2 = [0.12; 0.04]
- Sum: [0; 0] + [0.12; 0.04] = [0.12; 0.04]

**Apply sigmoid:**

- h₁[0] = σ(0.12) = 1/(1+e^(-0.12)) = 1/(1+0.887) = 0.530
- h₁[1] = σ(0.04) = 1/(1+e^(-0.04)) = 1/(1+0.961) = 0.510

**Result: h₁ = [0.530; 0.510]**

### Calculate y₁:

y₁ = W_hy × h₁ = [0.4 0.7] × [0.530; 0.510] = 0.4×0.530 + 0.7×0.510 = 0.212 + 0.357 = **0.569**
