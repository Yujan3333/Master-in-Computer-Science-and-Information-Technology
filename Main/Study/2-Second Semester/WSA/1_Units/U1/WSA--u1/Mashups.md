Mashups are interactive web applications that combine data from multiple external sources to create new, innovative services. They aggregate content from different locations to provide a unique, user-driven experience.

However, not all mashups are intelligent. To make them intelligent, the system must be able to identify similarities and reconcile differences between the combined data, which requires reference structures (like ontologies or knowledge bases).

Additionally, algorithms are needed to determine how elements from these reference structures fit into the retrieved content and how that content should be categorized and displayed.
