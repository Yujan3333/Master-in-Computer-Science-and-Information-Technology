That's a very common confusion. **They are related, but they are not the same.**

The difference is:

* **Site = "Where is the object located?"**
* **Association = "What other objects are found with it?"**

---

# 1. Site = Location

**Site** means the **physical location or position** of an object.

Ask yourself:

> **"Where is this object usually found?"**

### Example

A bridge is usually:

* Across a river ✅
* Across a valley ✅
* Across a railway ✅

Here, you're identifying the bridge based on **its location**.

```text
River
~~~~~~~~~~~~~~
      Bridge
=================
```

**The clue is the location.**

---

# 2. Association = Relationship

**Association** means the **relationship of one object with other nearby objects**.

Ask yourself:

> **"What objects are commonly found together?"**

### Example

You see:

* A river
* A road
* A bridge connecting the road across the river

You recognize it as a bridge because it is **associated with both the road and the river**.

```text
Road ========= Bridge ========= Road
                   |
~~~~~~~~~~~~~~~~River~~~~~~~~~~~~~~~
```

Here, you're using the **relationship between multiple objects**.

---

# Another Example: School

### Site

A school is usually located:

* Near residential areas
* Inside a town or village

This is **site** because you're using **location**.

---

### Association

You identify a school because you see:

* Playground
* School buses
* Sports field
* Parking area

These nearby features are **associated** with a school.

---

# Another Example: Airport

### Site

Airport:

* Usually on flat land
* Outside the city

➡️ **Site**

### Association

Airport is recognized because it has:

* Runway
* Taxiways
* Aircraft
* Terminal building

➡️ **Association**

# Easy Memory Trick

| Site       | Association     |
| ---------- | --------------- |
| **Where?** | **With what?**  |
| Location   | Relationship    |
| Position   | Nearby features |

# Bridge Example

| Question                             | Answer         | Element         |
| ------------------------------------ | -------------- | --------------- |
| **Where is the bridge?**             | Across a river | **Site**        |
| **What is connected to the bridge?** | Road + River   | **Association** |

---

## One-Line Memory Trick

* **Site = Location ("Where is it?")**
* **Association = Neighbors ("What is around it?")**

This distinction is what examiners expect. Even though the examples can involve the same object (like a bridge), **site focuses on the object's location**, while **association focuses on its relationship with surrounding features**.
