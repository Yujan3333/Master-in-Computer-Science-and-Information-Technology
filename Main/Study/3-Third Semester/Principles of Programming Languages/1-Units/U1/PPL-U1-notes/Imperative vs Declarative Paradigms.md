## Difference Between Imperative and Declarative Programming Paradigms (Exam Focused)

| **Imperative Paradigm**                                                                         | **Declarative Paradigm**                                                               |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 1. Focuses on **how** to solve the problem.                                                     | 1. Focuses on **what** result is required.                                             |
| 2. Program consists of a **sequence of commands/statements**.                                   | 2. Program consists of **logic, rules, or expressions** describing the desired result. |
| 3. **Control flow is explicitly specified** by the programmer (loops, if-else, function calls). | 3. **Control flow is handled automatically** by the language or runtime.               |
| 4. Programmer writes **step-by-step instructions** for execution.                               | 4. Programmer specifies the **goal**, not the execution steps.                         |
| 5. Changes the **program state** through assignments and updates to variables.                  | 5. Describes the **desired outcome** with minimal emphasis on changing state.          |
| 6. Generally easier to understand for beginners because execution is sequential.                | 6. Generally requires understanding of higher-level concepts like functions or logic.  |
| 7. Used for **general-purpose programming** and system/application development.                 | 7. Used for **problem solving, AI, mathematical computation, and database queries**.   |
| 8. Examples: **C, C++, Java (procedural/OOP), SQL (as listed in your notes under imperative)**. | 8. Examples: **LISP (functional), Prolog (logic)**.                                    |

## Easy Concept to Remember

### Imperative = Tell **HOW**

Suppose your friend asks how to reach your house.

You say:

1. Go straight.
2. Turn left.
3. Walk 100 meters.
4. Turn right.
5. My house is on the left.

➡ You are giving **step-by-step instructions**.

This is **Imperative Programming**.

---

### Declarative = Tell **WHAT**

Your friend asks for your address.

You simply say:

> "House No. 15, New Baneshwor, Kathmandu."

You don't explain the route. Your friend (or Google Maps) figures out **how** to reach.

➡ You specify **what** you want, not **how** to achieve it.

This is **Declarative Programming**.

### Exam Definition

**Imperative Paradigm:**
A command-driven programming paradigm in which the programmer specifies **how** a task should be performed using a sequence of statements.

**Declarative Paradigm:**
A programming paradigm in which the programmer specifies **what** result is required, while the language determines **how** to achieve it.
