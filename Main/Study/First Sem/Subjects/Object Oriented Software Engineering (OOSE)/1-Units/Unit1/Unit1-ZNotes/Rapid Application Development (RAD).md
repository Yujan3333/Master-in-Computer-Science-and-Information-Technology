## ✅ What is the RAD Model?

The **RAD (Rapid Application Development) Model** is a type of software development model that emphasizes **quick development and delivery** of software using **component-based construction**, **user feedback**, and **rapid prototyping**.

It focuses on **speed over perfection**, aiming to deliver a working product in a **short time**.

---

### 🔄 Phases of RAD Model:

1. **Business Modeling**  
    – Understand business requirements, information flow, and objectives.
    
2. **Data Modeling**  
    – Define and model data objects and how they relate.
    
3. **Process Modeling**  
    – Define how data will be used, processed, and transformed.
    
4. **Application Generation**  
    – Use tools to build system components quickly (using code generators or reusable components).
    
5. **Testing and Turnover**  
    – Test each component rapidly and deliver the final product to users.
    

---

### 🧠 Example:

You’re building a student result portal.  
Instead of writing everything from scratch, you reuse modules for login, dashboard, and data display — and finish it in 2–3 weeks with frequent user inputs.

---

### ✅ Advantages:

- Very **fast development**
    
- Continuous **user involvement and feedback**
    
- **Reusable components** reduce effort
    
- Encourages **early delivery** of working software
    

---

### ❌ Disadvantages:

- Not suitable for **large or complex** systems
    
- Requires **skilled developers**
    
- Heavily depends on **user involvement**
    
- Poor for systems with **tight performance requirements**

### 📌 Summary Line:

> The RAD model focuses on **rapid development**, **prototyping**, and **user feedback**, making it ideal for small-to-medium projects that need quick delivery.
