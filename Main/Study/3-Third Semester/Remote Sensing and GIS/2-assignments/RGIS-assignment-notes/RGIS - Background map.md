
# 🟢 STEP 1: Add a Map Background (VERY FIRST THING)

Right now your QGIS screen is empty, right?

### 👉 Do this:

1. Go to top menu → **Plugins**
2. Click → **Manage and Install Plugins**
3. Search: **QuickMapServices**
4. Click **Install**

---

### Now add map:

1. Go to → **Web**
2. Click → **QuickMapServices**
3. Click → **Google → Google Satellite**

---

✅ Now you should see a real map (like Google Maps)
