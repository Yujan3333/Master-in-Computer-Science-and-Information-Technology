#first-semester #advanced-operating-system

| **Aspect**      | **Critical Section Problem**                                                                                | **Race Condition**                                                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Definition**  | The problem of **designing a system** where multiple processes access shared resources **without conflict** | A situation that **occurs** when multiple processes access and modify shared data **at the same time**, leading to **unexpected results** |
| **Type**        | It is a **conceptual problem** that needs to be solved                                                      | It is a **real-world issue/error** that happens when the critical section problem is **not handled properly**                             |
| **Focus**       | Focuses on **preventing** simultaneous access to shared resources                                           | Focuses on the **consequence** of not preventing simultaneous access                                                                      |
| **Occurs When** | Occurs in **theoretical design** of concurrent systems                                                      | Occurs **at runtime** when synchronization fails                                                                                          |
| **Example**     | Designing an algorithm that ensures only one process enters a critical section at a time                    | Two processes updating a shared counter at the same time and ending up with the **wrong value**                                           |
| **Goal**        | To **prevent race conditions** by providing a proper solution                                               | To **be avoided** by solving the critical section problem                                                                                 |
