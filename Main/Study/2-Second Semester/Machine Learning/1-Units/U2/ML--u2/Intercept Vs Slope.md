
## ✅ **Slope (m)**

* It tells **how much the output (y)** changes when **x increases by 1 unit**.
* It measures the **steepness** or **tilt** of the line.
* If slope is:

  * **Positive** → line goes **upwards**
  * **Negative** → line goes **downwards**
  * **Zero** → line is **flat**

### Example:

If slope = 3 → for every +1 increase in x, y increases by +3.

---

## ✅ **Intercept (c or b₀)**

* It is the value of **y when x = 0**.
* It tells **where the line cuts the y-axis**.
* It is the **starting value** of y before x has any effect.

### Example:

If intercept = 5 → when x = 0, y = 5.

---

## 🧠 One-Line Intuition

* **Slope = effect of x on y**
* **Intercept = baseline value of y before x acts**

---

## 📌 Formula (Simple Linear Regression)

[y = mx + c]

* **m = slope**
* **c = intercept**
