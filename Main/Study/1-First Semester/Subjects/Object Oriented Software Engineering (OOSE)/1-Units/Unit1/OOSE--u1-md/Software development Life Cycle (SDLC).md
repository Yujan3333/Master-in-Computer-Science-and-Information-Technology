### 🔹 Definition:

The **Software Development Life Cycle (SDLC)** is a **structured process** used by software developers to **design, develop, test, and maintain** high-quality software.

It defines **phases** that ensure the project is delivered:

- On time ⏰
    
- Within budget 💰
    
- And meets user requirements ✅
    

---

## 🔄 Phases of SDLC (with short explanation):

|Phase|Description|
|---|---|
|**1. Requirement Analysis**|Gather and understand what the client or user needs.|
|**2. System Design**|Plan the architecture — how the software will look and work.|
|**3. Implementation (Coding)**|Developers write the actual code using suitable programming languages.|
|**4. Testing**|Check the software for bugs, errors, and if it meets the requirements.|
|**5. Deployment**|Release the software to users or move it to a production environment.|
|**6. Maintenance**|Fix issues, improve performance, and update features after deployment.|

## 📘 Example:

**Food Delivery App**:

1. 📋 Requirement: App must support login, menu browsing, ordering, and payments
    
2. 🏗️ Design: UI screens, database, APIs
    
3. 💻 Coding: Implement features like login page, order system
    
4. 🧪 Testing: Check if users can order and pay without bugs
    
5. 🚀 Deployment: Launch on Play Store / web
    
6. 🔧 Maintenance: Add offers, fix crashes, update security
