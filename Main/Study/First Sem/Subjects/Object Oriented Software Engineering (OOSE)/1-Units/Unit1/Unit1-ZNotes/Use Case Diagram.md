**Include Relationship:**

- **Purpose:** One use case always includes another use case's functionality
- **Notation:** Dashed arrow from including → included use case
- **Nature:** Mandatory integration
- **Example:** "Compose Post" includes "Add Image" - adding image is part of composing

**Extend Relationship:**

- **Purpose:** One use case optionally extends another under certain conditions
- **Notation:** Dashed arrow with "extend" keyword
- **Nature:** Optional/conditional behavior
- **Example:** "Select Seat" extends "Book Flight" - seat selection is optional
