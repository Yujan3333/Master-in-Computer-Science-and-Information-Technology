#first-semester #advanced-operating-system
The part of the operating system that manages  the **memory hierarchy** is called the memory  manager.

### Job
1. To keep track which part of the memory is currently in use or not in use.
2. Allocate memory to process and de-allocate when they don't need it
3. **Swapping** management between main memory and disk. [*Occurs When the main memory is to small to hold the process*]
