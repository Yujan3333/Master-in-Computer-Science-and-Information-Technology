# GPS vs GNSS

| **GPS**                                                                     | **GNSS**                                                             |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Global Positioning System**                                               | **Global Navigation Satellite System**                               |
| A satellite navigation system developed by the **United States**            | A general term for **all global satellite navigation systems**       |
| It is **one** navigation system                                             | It includes **multiple** navigation systems                          |
| Uses only **GPS satellites**                                                | Can use satellites from **GPS, GLONASS, Galileo, BeiDou**, etc.      |
| Usually provides lower satellite availability than multi-constellation GNSS | More satellites available, improving accuracy and reliability        |
| Part (subset) of GNSS                                                       | Umbrella term that includes GPS                                      |
| Examples: GPS receiver using only GPS satellites                            | Modern smartphones often use GNSS (GPS + GLONASS + Galileo + BeiDou) |

---

## Simple Diagram

```text
                 GNSS
      ┌───────────────────────┐
      │       GPS (USA)        │
      │    GLONASS (Russia)    │
      │   Galileo (Europe)     │
      │    BeiDou (China)      │
      └───────────────────────┘
```

**GPS is one part of GNSS.**

---

## Key Difference

* **GPS** = A **single** satellite navigation system developed by the **USA**.
* **GNSS** = The **general term** for **all** global satellite navigation systems, including GPS.

---

## Exam Definition

### GPS

> **GPS (Global Positioning System)** is a satellite-based navigation system developed by the United States that provides position, navigation, and timing information.

### GNSS

> **GNSS (Global Navigation Satellite System)** is the collective term for all satellite navigation systems that provide global positioning, navigation, and timing services.

---

## Easy Memory Trick

* **GPS = One system**
* **GNSS = Many systems**

Think of it like this:

* **GPS** is one **brand** of navigation satellites.
* **GNSS** is the **family** that includes GPS, GLONASS, Galileo, and BeiDou.

### Exam Tip

For a **2-mark question**, you can simply write:

1. **GPS** is a satellite navigation system developed by the **USA**.
2. **GNSS** is the umbrella term for all global satellite navigation systems.
3. **GPS is a subset of GNSS.**
