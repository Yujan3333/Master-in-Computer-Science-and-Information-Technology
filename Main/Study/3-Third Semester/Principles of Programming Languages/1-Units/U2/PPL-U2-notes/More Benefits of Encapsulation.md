## Advantages of Encapsulation (5 Marks)

**Encapsulation** is the process of combining data and methods into a single unit (class) while restricting direct access to the data.

### Advantages

1. **Data Hiding**

   * Internal data is hidden from outside the class.
   * Data can only be accessed through public methods.

2. **Improved Security**

   * Prevents unauthorized or accidental modification of data.
   * Protects the integrity of the object.

3. **Better Maintainability**

   * Internal implementation can be changed without affecting other parts of the program.
   * Makes code easier to update and debug.

4. **Improved Modularity**

   * Each class is a separate, self-contained unit.
   * Makes programs easier to organize and understand.

5. **Code Reusability**

   * Encapsulated classes can be reused in different programs.
   * Reduces code duplication.

6. **Controlled Access**

   * Access modifiers (`private`, `protected`, `public`) control how data is accessed.
   * Validation can be performed before modifying data.

7. **Reduced Complexity**

   * Users interact only with the public interface and do not need to know the internal implementation.

---

### Exam Answer (5 Marks)

**Advantages of Encapsulation:**

* Provides **data hiding** by restricting direct access to data.
* Improves **security** by preventing unauthorized modifications.
* Increases **maintainability** since implementation can change without affecting users.
* Promotes **modularity** by organizing code into self-contained classes.
* Enhances **code reusability** and reduces duplication.
* Allows **controlled access** through public methods and access modifiers.
