# SHA-512 (Secure Hash Algorithm-512)

> **Exam Importance:** ⭐⭐⭐⭐⭐ (Very Important)

---

# Q. What is SHA-512? Explain its working, features, and applications.

---

# Answer

# Introduction

**SHA-512 (Secure Hash Algorithm-512)** is a member of the **SHA-2 family** of cryptographic hash functions, designed by the **U.S. National Security Agency (NSA)** and standardized by **NIST**.

It generates a **512-bit (64-byte)** hash value from an input message of **any length** and is widely used to ensure **data integrity**, **digital signatures**, and **message authentication**.

SHA-512 is considered much more secure than SHA-1 and is currently one of the most widely used cryptographic hash functions.

---

# Definition

**SHA-512** is a cryptographic hash function that accepts a message of arbitrary length and produces a **512-bit fixed-length message digest**.

Mathematically,

$$
H = \text{SHA-512}(M)
$$

where

* $M$ = Input message
* $H$ = 512-bit hash value

---

# Characteristics of SHA-512

* Accepts **variable-length input**.
* Produces a **512-bit fixed-length output**.
* Deterministic (same input → same output).
* One-way function.
* Collision resistant.
* Exhibits the avalanche effect.
* Faster on **64-bit processors** than SHA-256.

---

# Working of SHA-512

SHA-512 processes the message in several stages.

---

## Step 1: Padding

The message is padded by:

* Appending a single **1** bit.
* Adding enough **0** bits.
* Appending a **128-bit representation of the original message length**.

After padding,

the total message length becomes a multiple of **1024 bits**.

---

## Step 2: Divide into Blocks

The padded message is divided into **1024-bit blocks**.

```text
Message

↓

Padding

↓

1024-bit Blocks

B1 | B2 | B3 | ... | Bn
```

---

## Step 3: Initialize Hash Values

SHA-512 starts with **eight predefined 64-bit initial hash values**.

$$
H_0, H_1, H_2, H_3, H_4, H_5, H_6, H_7
$$

These are fixed constants defined in the SHA-512 standard.

---

## Step 4: Message Schedule

Each **1024-bit block** is divided into **16 words** of **64 bits** each.

These 16 words are expanded into **80 words**.

```text
16 Words

↓

Expansion

↓

80 Words
```

This expanded message schedule is used in the compression process.

---

## Step 5: Compression Function

Each message block is processed through **80 rounds**.

During each round,

* Logical operations
* Bitwise rotations
* Modular additions
* Boolean functions

are performed.

The working variables are continuously updated.

---

## Step 6: Update Hash Values

After all 80 rounds,

the intermediate hash values are updated.

The process repeats for every message block.

---

## Step 7: Produce Final Hash

After processing the final block,

the eight hash values are concatenated.

The result is the **512-bit message digest**.

---

# Working Diagram

```text
                 Input Message
                       │
                       ▼
                   Padding
                       │
                       ▼
            Divide into 1024-bit Blocks
                       │
                       ▼
             Initialize Hash Values
          (H0, H1, H2, H3, H4, H5, H6, H7)
                       │
                       ▼
            Expand Block into 80 Words
                       │
                       ▼
              Compression Function
                 (80 Rounds)
                       │
                       ▼
              Update Hash Values
                       │
                       ▼
             Repeat for All Blocks
                       │
                       ▼
             512-bit Final Hash
```

# Structure of SHA-512

| Parameter           | Value                   |
| ------------------- | ----------------------- |
| Input size          | Variable                |
| Output size         | **512 bits (64 bytes)** |
| Block size          | **1024 bits**           |
| Word size           | **64 bits**             |
| Number of rounds    | **80**                  |
| Initial hash values | 8 × 64-bit words        |

---

# Security Properties

SHA-512 provides:

* ✅ Data Integrity
* ✅ Collision Resistance
* ✅ Preimage Resistance
* ✅ Second Preimage Resistance
* ✅ Avalanche Effect

It does **not** provide:

* ❌ Confidentiality
* ❌ Encryption

---

# Advantages

* Very high security.
* Extremely difficult to find collisions.
* Supports digital signatures.
* Suitable for very large files.
* Faster than SHA-256 on many 64-bit systems.

---

# Limitations

* Produces a larger hash than SHA-256, requiring more storage.
* Does not provide confidentiality.
* Slightly slower on 32-bit processors.

---

# Applications

SHA-512 is used in:

* Digital Signatures
* HMAC
* SSL/TLS
* File Integrity Verification
* Blockchain
* Password Hashing (with appropriate password-hashing schemes)
* Software Verification

---

# SHA-256 vs SHA-512

| Feature          | SHA-256           | SHA-512           |
| ---------------- | ----------------- | ----------------- |
| Output size      | 256 bits          | 512 bits          |
| Block size       | 512 bits          | 1024 bits         |
| Word size        | 32 bits           | 64 bits           |
| Number of rounds | 64                | 80                |
| Best suited for  | 32-bit processors | 64-bit processors |
| Security         | Very High         | Higher            |

---

# SHA-1 vs SHA-512

| SHA-1                   | SHA-512                              |
| ----------------------- | ------------------------------------ |
| 160-bit output          | 512-bit output                       |
| 80 rounds               | 80 rounds                            |
| Collision attacks exist | No practical collision attacks known |
| Not recommended         | Recommended                          |

---

# Key Points to Remember

* SHA-512 belongs to the **SHA-2 family**.
* Produces a **512-bit** hash.
* Processes data in **1024-bit blocks**.
* Uses **64-bit words**.
* Performs **80 rounds** per block.
* Starts with **8 initial hash values**.
* Provides **integrity**, **not confidentiality**.
