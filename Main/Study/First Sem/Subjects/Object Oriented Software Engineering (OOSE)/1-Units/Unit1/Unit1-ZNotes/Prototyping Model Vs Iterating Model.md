|**Aspect**|**Prototyping Model**|**Iterative Model**|
|---|---|---|
|**Main Focus**|Build a **quick prototype** to understand user requirements|Build the system **in parts (iterations)** with added features|
|**Purpose**|Clarify **unclear or evolving** requirements early|Gradually **improve and expand** the system|
|**User Involvement**|High — users test and give feedback on the prototype|Moderate — feedback is used after each iteration|
|**Final System**|Built **after** refining the prototype|Built **during** iterations, each improving on the last|
|**Prototype Usage**|Prototype is often **thrown away** after use|Each iteration is **part of the final system**|
|**Suitable For**|Projects with **unclear requirements**|Projects that need **frequent enhancements or improvements**|
|**Example**|UI/UX-heavy apps where user feedback is crucial|Large apps like CRMs or ERPs built module-by-module|
