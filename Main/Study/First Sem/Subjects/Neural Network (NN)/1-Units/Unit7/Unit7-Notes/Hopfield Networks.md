
### 🧠 **Hopfield Network Summary**

**Hopfield Networks** are a type of **single-layer recurrent neural network** used for **associative memory** and **pattern recognition**.

![](../../../../../../../../Images/First_Sem_Images/Hopfield%20Networks.png)

---

### 🔑 **Key Features:**

* Consists of **n fully connected neurons** (every neuron connects to every other neuron).
* Each neuron acts as **both input and output**.
* **No self-connections**: A neuron cannot connect to itself.
* Functions as **content-addressable memory**:
  When a **new pattern** is input, the network **recalls the closest stored pattern**.

---

### 🔄 **Types:**

1. **Discrete Hopfield Network**

   * **Binary**: Outputs are 0 or 1
   * **Bipolar**: Outputs are +1 or –1

2. **Continuous Hopfield Network**

   * Neuron activations take continuous values
   * Modeled using differential equations

---

### 📌 **Applications:**

* Pattern recognition
* Associative memory
* Solving optimization problems (e.g., traveling salesman)
