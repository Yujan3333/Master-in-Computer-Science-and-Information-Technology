You can draw a straight line (or a plane in higher dimensions) that completely separates the data points of different classes.

### 🟢 Example (2D):

If you have points like this:

- Class 0: (1, 1), (2, 2)
    
- Class 1: (4, 4), (5, 5)
    
You **can draw a straight line** between them to separate the two classes.

✅ This is **linearly separable**.

---

### 🔴 Non-Linearly Separable:

In XOR logic:

- Class 0: (0, 0), (1, 1)
    
- Class 1: (0, 1), (1, 0)
    

You **can’t draw one straight line** to separate the classes.

❌ This is **not linearly separable**.
