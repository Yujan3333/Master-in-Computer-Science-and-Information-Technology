

|Aspect|Binary Tree|Binary Search Tree (BST)|
|---|---|---|
|Definition|Each node has max 2 children|A binary tree with sorted ordering property|
|Node Ordering|No specific rule|Left < Root < Right|
|Search Efficiency|O(n) (no structure to guide search)|O(log n) average (due to sorted structure)|
|Use Cases|Expression trees, Heaps, Syntax trees|Searching, dynamic sorting, associative arrays|
|Duplicate Elements|Can be allowed|Usually not allowed (or stored consistently)|
|Example Structure|Random|Sorted|
