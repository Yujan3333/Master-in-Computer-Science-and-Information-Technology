

## 🌟 What is OOA?

**Object-Oriented Analysis (OOA)** is the process of understanding the **problem** you're trying to solve and **modeling it using objects** that represent real-world things.

- We **identify objects**, their **attributes** (data), and their **behaviors** (actions).
    
- We **don’t worry about code yet** — we just figure out _what_ the system needs to do.
    

---

## ✅ Real-World Examples of OOA

---

### 🏦 **1. Banking System**

#### Identified Objects:

- `Customer`
    
- `Account`
    
- `Transaction`
    
- `ATM`
    

#### Attributes:

- `Customer`: name, address, phone
    
- `Account`: account number, balance
    
- `Transaction`: amount, date
    

#### Behaviors:

- `Customer`: open account, update profile
    
- `Account`: deposit, withdraw, check balance
    
- `Transaction`: execute, cancel
    

---

### 🏥 **2. Hospital Management System**

#### Identified Objects:

- `Patient`
    
- `Doctor`
    
- `Appointment`
    
- `MedicalRecord`
    

#### Attributes:

- `Patient`: ID, name, age
    
- `Doctor`: specialty, ID, name
    
- `Appointment`: date, time
    

#### Behaviors:

- `Patient`: book appointment, check status
    
- `Doctor`: view schedule, write prescription
    
- `Appointment`: schedule, cancel
    

---

### 📚 **3. Library Management System**

#### Identified Objects:

- `Book`
    
- `Member`
    
- `Librarian`
    
- `Loan`
    

#### Attributes:

- `Book`: title, author, ISBN
    
- `Member`: ID, name, membership date
    

#### Behaviors:

- `Member`: borrow book, return book
    
- `Book`: check availability
    
- `Loan`: issue, due date calculation
    

---

### 🛒 **4. Online Shopping System**

#### Identified Objects:

- `User`
    
- `Product`
    
- `Cart`
    
- `Order`
    

#### Attributes:

- `User`: name, email, address
    
- `Product`: ID, price, description
    
- `Order`: order ID, date, payment status
    

#### Behaviors:

- `User`: login, browse, checkout
    
- `Cart`: add item, remove item
    
- `Order`: place order, track order
    

---

### 🎮 **5. Game Development (e.g., Platformer Game)**

#### Identified Objects:

- `Player`
    
- `Enemy`
    
- `Obstacle`
    
- `ScoreBoard`
    

#### Attributes:

- `Player`: health, position, name
    
- `Enemy`: type, damage
    
- `Obstacle`: size, location
    

#### Behaviors:

- `Player`: move, jump, attack
    
- `Enemy`: patrol, chase
    
- `ScoreBoard`: update score
    

---

## 🧠 Summary

|Term|Meaning Example (Library)|
|---|---|
|Object|Real-world thing → `Book`|
|Attribute|Data it holds → `title`, `author`|
|Behavior|What it does → `issue()`, `return()`|
