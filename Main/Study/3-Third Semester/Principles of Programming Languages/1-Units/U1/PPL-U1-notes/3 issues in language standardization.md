# Q. Explain the three issues in language standardization.

## 1. Timeliness

**Definition:**
Timeliness refers to **deciding the right time to standardize a programming language**.

**Explanation:**

* A language should **not be standardized too early**, because it may not have been tested enough.
* It should also **not be standardized too late**, because many incompatible versions may already exist.

**Example:**
If a language is standardized after many companies create different versions, programs may not work the same on every compiler.

**Keyword:** **Right time to standardize**

---

## 2. Conformance

**Definition:**
Conformance means **following the language standard correctly**.

**Explanation:**

* A **conformant program** uses only the features defined in the standard.
* A **conforming compiler** correctly compiles such programs and produces the expected output.

**Example:**
A standard C program should compile and run correctly on any standard-compliant C compiler.

**Keyword:** **Following the standard**

---

## 3. Obsolescence

**Definition:**
Obsolescence refers to **a standard becoming outdated over time**.

**Explanation:**

* Technology changes continuously.
* New hardware and programming techniques require new language features.
* Therefore, standards must be updated periodically.

**Example:**
Older C standards did not include features available in modern versions like C11 or C23.

**Keyword:** **Updating old standards**

## Exam Answer (5 Marks)

**Q. What are the three issues in language standardization?**

**Ans:**

1. **Timeliness:** A language should be standardized at the appropriate time—not too early and not too late.
2. **Conformance:** Programs and compilers should follow the language standard to ensure correct and portable execution.
3. **Obsolescence:** As technology evolves, language standards become outdated and must be revised to support new features.

### Memory Trick

**TCO = Time → Conform → Obsolete**

* **T** = **Timeliness** → *When* to standardize.
* **C** = **Conformance** → *Follow* the standard.
* **O** = **Obsolescence** → *Update* the standard.
